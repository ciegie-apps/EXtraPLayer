# EXtraPLayer is a music player for plex servers. 

## EXtraPLayer's Focus on Metadata Display
It is targeted at users who want to see more than only the usual metadata of the track and album. EXtraPLayer displays, if available in the plex database and for the user
- the user rating of track and album
- the genres of the played track
- the year of the track or, as a backup, the album year 
- moods
- the number of plays and the date of the last playback are displayed
- the track path on the hard drive
- the Track RatingKey, and the Album RatingKey (IDs of track and album)
- album review 
- artist bio.

## Limitations for Managed Users
You must have access to a plex music library to use this app.
While **server owners** may see all of the metadata above if the database has this information, plex restricts data access for **managed users** to a subset of these data.
Therefore using the app is recommended only to those who run their own server.
